## What FallRecruit Does

FallRecruit consolidates everyday recruitment administration into one browser-based tool. Candidate records, client information, vacancies, and placements can all be managed from a single HTML application without a conventional installation process.

Its offline-first design uses storage on the local device and browser. The app is intended for recruiters, small recruitment agencies, and independent operators who need a compact way to organize hiring activity, monitor compliance information, and check operational KPIs from a dashboard.

---

## Core Capabilities

- Operational dashboard with KPI summaries
- Candidate records that include right-to-work and DBS fields
- Client profiles with terms and sector details
- Vacancy records with IR35 status information
- Placement monitoring with AWR week counts and invoicing support
- Compliance checklist for keeping required follow-up visible
- Persistent data saved in browser-local storage
- BYOK Anthropic Q&A functionality for assisted interactions

## Getting Started

Because FallRecruit is distributed as one HTML file, there is no traditional installer.

1. Download or clone the repository.
2. Launch the main HTML file with a modern browser.
3. Begin using the application with browser local storage enabled.

For self-hosting, copy the HTML file into any suitable directory or static hosting location, then open it through your chosen setup.

## Working with the App

A common operating sequence looks like this:

1. Launch FallRecruit in a browser.
2. Enter the candidates, clients, vacancies, and placements relevant to your work.
3. Use the dashboard to review current activity and status.
4. Maintain process details through the tracking fields and compliance checklist.
5. Reopen the app on the same device when you need to continue working.

For example, you can:

- Add a candidate together with right-to-work and DBS information.
- Set up a client record and capture its terms and sector.
- Create a vacancy and specify its IR35 status.
- Record a placement, follow AWR week counts, and retain invoicing information.

## Data and Configuration

FallRecruit writes its records to the browser's local storage on the device in use. Clearing site data or moving to a different browser will not automatically transfer those records.

The Anthropic Q&A option uses your own key when enabled. Any required setup is performed within the application environment rather than in a separate desktop configuration file.

## Frequently Asked Questions

### Is an installation required?
No. FallRecruit is intended to open directly in a browser from its single HTML file.

### How are records saved?
Records are kept in local browser storage on the device where FallRecruit is running.

### Will clearing browser storage affect my records?
Yes. Clearing browser data can remove the records saved by the application.

### Can I use the app offline?
The core application follows an offline-first model and is intended to work without continuous internet access.

### How can I move to a newer release?
Download the newest build from the project link, then replace your existing copy when appropriate.

### What should I check if Q&A does not respond?
Verify that your Anthropic key has been entered correctly and confirm that the browser environment is able to make the necessary requests.
